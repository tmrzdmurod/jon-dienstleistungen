# Jon Dienstleistungen — сайт монтажа солнечных панелей

Сайт небольшой фирмы из Эрлангена (Германия): лендинг услуги монтажа солнечных панелей,
запись на дату через календарь, личный кабинет клиента, кабинет сотрудника и админ-панель.
Интерфейс сайта — на немецком. Цена на сайте нигде не фиксирована: мастер называет её
после осмотра, по объёму работы («Preis nach Vereinbarung»).

## Что умеет

| Раздел | Возможности |
| --- | --- |
| Главная | Фото работ, карточка «как формируется цена», этапы монтажа, анкета из 4 шагов с отправкой в WhatsApp, галерея, услуги, FAQ, отзывы с фильтром |
| Клиент | Регистрация, запись на свободный день, статус заявок, отзыв после одобренной заявки, смена пароля |
| Сотрудник | Свои задачи, подтверждение новых, смена статуса, обязательная смена стартового пароля |
| Админ | Обзор с показателями, заявки (одобрить/отклонить, массово), отзывы и ответы, клиенты, сотрудники, распределение задач, отчёты, экспорт CSV |

## Технологии

PHP 8.4 без фреймворков, MySQL/MariaDB, Apache (`.htaccess`), чистые CSS и JavaScript.
Сторонние библиотеки не нужны, кроме иконок Font Awesome с CDN.

## Запуск локально

1. Положить проект в папку веб-сервера (например, OSPanel: `home/sunpanel`).
2. Создать базу: импортировать `solar.sql` (только структура, без данных).
3. Скопировать `config.local.example.php` в `config.local.php` и вписать доступ к базе.
4. Задать вход администратора (сохраняется только хеш пароля, заодно создаётся `JWT_SECRET`):

   ```bash
   php bin/set-admin-password.php
   ```

5. Открыть сайт в браузере. Без веб-сервера можно так: `php -S 127.0.0.1:8099`
   (правила `.htaccess` при этом не действуют — только для разработки).

## Уведомления

| Событие | Кому | Канал |
| --- | --- | --- |
| Новая заявка из календаря | мастеру/владельцу | e-mail и WhatsApp |
| Админ одобрил или отклонил заявку | клиенту | e-mail |

Настройки — в `config.local.php` (образец в `config.local.example.php`):

- **E-mail через SMTP**, например GMX: `mail.gmx.net`, порт `587`, `tls`, логин — адрес почты.
  Для локальной проверки подходит Mailpit из OSPanel (`127.0.0.1:1025`, шифрование `none`).
- **WhatsApp**, на выбор:
  - `callmebot` — бесплатно, только на собственный номер владельца. Ключ выдаётся один раз
    после сообщения боту CallMeBot (инструкция на callmebot.com).
  - `cloud` — официальный WhatsApp Cloud API от Meta. Нужен бизнес-аккаунт, токен,
    ID номера и одобренный шаблон сообщения с одним параметром `{{1}}`.
  - `log` — только запись в журнал, для разработки.

Отправка выполняется после ответа браузеру, поэтому медленный почтовый сервер не задерживает запись.
Ошибки пишутся в `tmp/notifications.log`. Статус каналов, кнопка «Test senden» и последние попытки
отправки — на странице «Übersicht» в админке.

## Безопасность

- **Вход — JWT (HS256)** в HttpOnly-cookie, отдельный токен для клиента, админа и сотрудника
  (`auth.php`). Алгоритм зафиксирован, у токена есть срок действия, продление при активности,
  предельный срок с момента входа и отзыв при выходе. Админский токен живёт 30 минут без активности.
- **Подбор пароля** блокируется: 5 неудачных попыток на аккаунт или 20 с одного IP за 15 минут.
- **Секреты** (`JWT_SECRET`, доступ к БД, вход админа) лежат только в `config.local.php`,
  который не попадает в git. Новый `JWT_SECRET` (`php bin/set-admin-password.php --logout-all`)
  завершает все сессии.
- **`.htaccess`** закрывает `tmp/` (сессии, хеши паролей), `bin/`, `tests/`, `partials/`, дампы и логи.
  На nginx эти правила нужно перенести в конфигурацию сервера.
- Формы защищены CSRF-токенами.

## Тесты

```bash
php tests/auth_test.php
php tests/notify_test.php                          # тексты, WhatsApp-запросы, сборка письма
php tests/notify_test.php --smtp=127.0.0.1:1025    # плюс настоящая отправка через Mailpit
```

`auth_test.php` проверяет подделку и истечение токенов, `alg: none`, чужую область доступа, отзыв токена,
блокировку подбора пароля и сравнение пароля админа.

## Структура

```
index.php, calendar.php, …   страницы
auth.php                      JWT-вход, блокировка подбора
notify.php                    уведомления: SMTP и WhatsApp
partials/layout.php           общая шапка, навигация, подвал, контакты
styles/site.css               общие цвета, шрифты, кнопки
styles/*.css                  стили отдельных страниц
js/                           скрипты главной и общие
bin/set-admin-password.php    смена входа администратора
tests/                        тесты авторизации и уведомлений
solar.sql                     структура базы данных
```
